# rust-chatgpt-cli 

A simple and practical Rust-based CLI demo for interacting with ChatGPT from the terminal.

This project shows how to build a lightweight command-line tool in Rust that sends a prompt to the OpenAI API and prints the response directly in your console.

## Overview

`rust-chatgpt-cli` is a minimal demo project created to demonstrate how Rust can be used to build modern AI-powered developer tools.

With this CLI, you can:

- send prompts directly from your terminal
- experiment with OpenAI integrations in Rust
- use the project as a starting point for your own AI CLI tools

## Prerequisites

Before running this project, make sure you have the following installed:

- [Rust and Cargo](https://www.rust-lang.org/tools/install)
- an OpenAI API key

You must also configure your API key as an environment variable.

## Environment Setup

Set your OpenAI API key in your environment before running the project.

### Linux / macOS

```bash
export OPENAI_APIKEY="your_api_key_here"
